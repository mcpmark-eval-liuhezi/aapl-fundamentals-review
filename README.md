# aapl-fundamentals-review

Fundamentals pack for **Apple Inc. (AAPL)**, assembled for our investment club's monthly company deep-dive.

## What's in this repository

- **[report.md](report.md)** — the complete fundamentals pack, one section per topic:
  1. Annual statements (income statement, balance sheet, cash flow statement)
  2. Quarterly trend (five most recent quarters)
  3. Profile and valuation
  4. Ownership (overall breakdown + top institutional holders)
  5. Dividends and splits
  6. Analyst moves (past 12 months)
  7. Recent news
  8. 1-year price performance

  All figures are exactly as returned by Yahoo Finance on 2026-10-23, each labeled with the period it belongs to.

- **`.github/workflows/refresh.yml`** — a manually triggered (`workflow_dispatch`) GitHub Actions workflow that checks out the repository and echoes that the pack is current. Run it from the **Actions** tab whenever you want to re-verify the pack.

## Housekeeping

The notification subscription for this repository is set to **ignore**, so workflow runs will not flood anyone's inbox.
